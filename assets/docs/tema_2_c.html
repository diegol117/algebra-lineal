MÓDULO 01 $\mathbb{R}^n$ como Espacio Euclídeo

Los conceptos de ortogonalidad nos permiten generalizar la geometría euclidiana clásica a espacios de $n$ dimensiones. En el plano y el espacio físico comprendemos intuitivamente qué significa que dos líneas sean perpendiculares o cómo un objeto proyecta una sombra sobre una superficie; a partir de esta intuición construimos una estructura robusta para descomponer espacios, optimizar cálculos y —más adelante— encontrar aproximaciones óptimas en sistemas de ecuaciones sin solución exacta.

1.1 Producto Escalar Euclídeo

📌 Definición 6.1

Sean $\vec{u}, \vec{v} \in \mathbb{R}^n$. El producto escalar euclídeo, denotado $\vec{u}\cdot\vec{v}$, es el número real

\[ \begin{aligned} \vec{u}\cdot\vec{v} &= \vec{u}^t\vec{v} \\[0.5em] &= u_1v_1 + u_2v_2 + \dots + u_nv_n. \end{aligned} \]
📐 Teorema 6.1 (propiedades)
  1. $\vec{u}\cdot\vec{v} = \vec{v}\cdot\vec{u}$
  2. $(\vec{u}+\vec{v})\cdot\vec{w} = \vec{u}\cdot\vec{w} + \vec{v}\cdot\vec{w}$
  3. $(c\vec{u})\cdot\vec{v} = c(\vec{u}\cdot\vec{v}) = \vec{u}\cdot(c\vec{v})$
  4. $\vec{u}\cdot\vec{u} \ge 0$, y $\vec{u}\cdot\vec{u}=0 \Leftrightarrow \vec{u}=\vec{0}$

Combinando (b) y (c): para cualquier combinación lineal se cumple

\[ \begin{aligned} (c_1\vec{u}_1 + \dots + c_p\vec{u}_p)\cdot\vec{w} &= c_1(\vec{u}_1\cdot\vec{w}) + \dots \\[0.5em] &\quad + c_p(\vec{u}_p\cdot\vec{w}). \end{aligned} \]

1.2 Norma o Longitud de un Vector

📌 Definición 6.2

La norma o longitud de $\vec{v}\in\mathbb{R}^n$ es

\[ \begin{aligned} \|\vec{v}\| &= \sqrt{\vec{v}\cdot\vec{v}} \\[0.5em] &= \sqrt{v_1^2 + v_2^2 + \dots + v_n^2}. \end{aligned} \]

En $\mathbb{R}^2$ coincide con la longitud del segmento del origen a $(a,b)$ (Pitágoras); en $\mathbb{R}^3$ es la diagonal del paralelepípedo con lados $a, b, c$.

Para cualquier escalar $c$: $\|c\vec{v}\| = |c|\|\vec{v}\|$. Un vector unitario es aquel con $\|\vec{u}\|=1$. Normalizar un vector $\vec{v}\ne\vec{0}$ consiste en:

\[ \begin{aligned} \vec{u} &= \frac{1}{\|\vec{v}\|}\,\vec{v}, \\[0.5em] \|\vec{u}\| &= 1. \end{aligned} \]
Norma como longitud del segmento

1.3 Distancia en $\mathbb{R}^n$

📌 Definición 6.3

La distancia entre $\vec{u}$ y $\vec{v}$ es la longitud de $\vec{u}-\vec{v}$:

\[ \begin{aligned} \operatorname{dist}(\vec{u},\vec{v}) &= \|\vec{u}-\vec{v}\| \\[0.5em] &= \sqrt{(\vec{u}-\vec{v})\cdot(\vec{u}-\vec{v})}. \end{aligned} \]
💡 Definición 6.4: espacio euclídeo

$\mathbb{R}^n$ es un espacio euclídeo porque admite producto interno, norma y distancia, todas derivadas del mismo producto escalar.

1.4 Ángulo entre Vectores

El ángulo entre $\vec{u}$ y $\vec{v}$ (no nulos) es $\alpha \in [0,\pi]$ tal que

\[ \begin{aligned} \vec{u}\cdot\vec{v} &= \|\vec{u}\|\,\|\vec{v}\|\cos\alpha \\[0.5em] &\Longrightarrow \cos\alpha = \frac{\vec{u}\cdot\vec{v}}{\|\vec{u}\|\,\|\vec{v}\|}. \end{aligned} \]
  • $\vec{u}\cdot\vec{v} = 0 \Leftrightarrow \alpha = \pi/2$ (perpendiculares).
  • $\vec{u}\cdot\vec{v} > 0 \Leftrightarrow \alpha \in [0,\pi/2)$ (ángulo agudo).
  • $\vec{u}\cdot\vec{v} < 0 \Leftrightarrow \alpha \in (\pi/2,\pi]$ (ángulo obtuso).

MÓDULO 02 Ortogonalidad y Bases Ortonormales

2.1 Vectores Ortogonales

📌 Definición 6.5

Dos vectores $\vec{u},\vec{v}\in\mathbb{R}^n$ son ortogonales si $\vec{u}\cdot\vec{v}=0$.

El vector nulo es ortogonal a todos los vectores, pues $\vec{0}^t\vec{v}=0$ para todo $\vec{v}$.

📐 Teorema 6.2 (Pitágoras)

$\vec{u}$ y $\vec{v}$ son ortogonales si y solo si $\|\vec{u}+\vec{v}\|^2 = \|\vec{u}\|^2 + \|\vec{v}\|^2$.

2.2 Conjuntos Ortogonales y Ortonormales

📌 Definiciones 6.6 y 6.7
  • Conjunto ortogonal: $\vec{u}_i \cdot \vec{u}_j = 0$ si $i \ne j$.
  • Conjunto ortonormal: conjunto ortogonal de vectores unitarios: $\vec{u}_i\cdot\vec{u}_j = 0$ si $i \ne j$, y $\vec{u}_i\cdot\vec{u}_i = 1$.
📐 Teorema 6.3

Todo conjunto ortogonal de vectores no nulos en $\mathbb{R}^n$ es linealmente independiente y, por tanto, es una base del espacio que genera.

Base ortogonal: base que además es conjunto ortogonal. Base ortonormal: base que además es conjunto ortonormal. Al normalizar un conjunto ortogonal (dividir cada vector por su norma) sigue siendo ortogonal y pasa a ser ortonormal.

Base canónica: ortonormal

2.3 Bases Ortogonales y Coordenadas

📐 Teorema 6.4 (coordenadas en base ortogonal)

Sea $\{\vec{u}_1,\dots,\vec{u}_p\}$ una base ortogonal de $W$. Las coordenadas de $\vec{y}\in W$ son

\[ \begin{aligned} c_j &= \frac{\vec{y}\cdot\vec{u}_j}{\vec{u}_j\cdot\vec{u}_j}, \\[0.5em] j &= 1,\dots,p. \end{aligned} \]
📐 Corolario 6.1 (base ortonormal)

Si la base es ortonormal, la fórmula se simplifica a $c_j = \vec{y}\cdot\vec{u}_j$.

Esto explica por qué una base ortogonal es mucho más sencilla de tratar: las coordenadas se obtienen con un simple producto punto, sin resolver sistemas lineales.

2.4 Matriz Ortogonal

📐 Teorema 6.5

Una matriz real $Q_{n\times n}$ es ortogonal (es decir, $Q^{-1} = Q^t)$ si y solo si sus columnas forman una base ortonormal de $\mathbb{R}^n$.

Si $Q$ es ortogonal, sus columnas forman una base ortonormal, y se cumple $Q^tQ = QQ^t = I$. Las matrices ortogonales preservan producto interno, norma y ángulo: $\|Q\vec{x}\| = \|\vec{x}\|$.

2.5 Subespacios Ortogonales

📌 Definiciones 6.10 y 6.11
  • $\vec{z}$ es ortogonal a un subespacio $W$ si $\vec{z}\cdot\vec{w} = 0$ para todo $\vec{w}\in W$.
  • Dos subespacios $V$ y $W$ son ortogonales si todo $\vec{z}\in V$ es ortogonal a $W$.

MÓDULO 03 Complemento Ortogonal y Proyecciones

Una vez dominada la proyección sobre una única dirección, el paso natural es extender la idea a subespacios de mayor dimensión. Imaginemos proyectar un vector sobre un plano completo; aquí surge la necesidad de dividir el espacio total en dos partes independientes y perpendiculares.

3.1 Complemento Ortogonal $H^\perp$

📌 Definición 6.12

El complemento ortogonal de $H$ en $\mathbb{R}^n$ es

\[ H^\perp = \{\vec{z}\in\mathbb{R}^n : \vec{z}\cdot\vec{h} = 0 \ \forall\, \vec{h}\in H\}. \]
📐 Teorema 6.6
  1. $\vec{x}\in H^\perp$ si y solo si $\vec{x}$ es ortogonal a todos los vectores de un sistema de generadores de $H$.
  2. $H^\perp$ es un subespacio de $\mathbb{R}^n$.
  3. $H \oplus H^\perp = \mathbb{R}^n$ (suma directa).

En particular, se cumplen:

  • $\dim H + \dim H^\perp = n$.
  • $H \cap H^\perp = \{\vec{0}\}$.
  • Todo subespacio admite infinitos complementos (no necesariamente ortogonales), pero solo uno es ortogonal.

3.2 Descomposición Ortogonal

Como $\mathbb{R}^n = H\oplus H^\perp$, cada $\vec{y}\in\mathbb{R}^n$ se escribe de forma única como

\[ \begin{aligned} \vec{y} &= \hat{\vec{y}} + \vec{z}, \\[0.5em] \hat{\vec{y}} &\in H, \quad \vec{z} \in H^\perp. \end{aligned} \]

$\hat{\vec{y}} = \text{proy}_H\vec{y}$ es la proyección ortogonal de $\vec{y}$ sobre $H$; $\vec{z}$ es la componente perpendicular (o “error”).

3.3 Fórmula de la Proyección Ortogonal

📐 Teorema 6.7 (base ortogonal)

Si $\{\vec{u}_1,\dots,\vec{u}_p\}$ es una base ortogonal de $H$ y $\vec{y}\in\mathbb{R}^n$, entonces

\[ \begin{aligned} \text{proy}_H\vec{y} &= \frac{\vec{y}\cdot\vec{u}_1}{\vec{u}_1\cdot\vec{u}_1}\vec{u}_1 + \dots \\[0.5em] &\quad + \frac{\vec{y}\cdot\vec{u}_p}{\vec{u}_p\cdot\vec{u}_p}\vec{u}_p. \end{aligned} \]

Si la base es ortonormal, la fórmula se simplifica:

\[ \begin{aligned} \text{proy}_H\vec{y} &= (\vec{y}\cdot\vec{u}_1)\vec{u}_1 + \dots \\[0.5em] &\quad + (\vec{y}\cdot\vec{u}_p)\vec{u}_p. \end{aligned} \]
💡 Comentario práctico

Para cálculos a mano, conviene usar la primera fórmula (base ortogonal); la segunda (base ortonormal) trae raíces que a veces complican las operaciones.

Para un subespacio de dimensión 1 (una recta de dirección $\vec{u}$):

\[ \text{proy}_{\vec{u}}\vec{y} = \frac{\vec{y}\cdot\vec{u}}{\vec{u}\cdot\vec{u}}\,\vec{u}. \]

Si $\vec{y}\in H$, entonces $\text{proy}_H\vec{y}=\vec{y}$ (corolario 6.2).

3.4 Mejor Aproximación y Distancia

📐 Mejor aproximación

La proyección ortogonal $\text{proy}_H\vec{y}$ es el vector de $H$ más cercano a $\vec{y}$. Para cualquier $\vec{h}\in H$, $\vec{h}\ne\text{proy}_H\vec{y}$:

\[ \|\vec{y} - \text{proy}_H\vec{y}\| < \|\vec{y} - \vec{h}\|. \]

El vector error $\vec{\varepsilon} = \vec{y} - \text{proy}_H\vec{y}$ pertenece a $H^\perp$ y minimiza la suma de errores al cuadrado. La distancia de $\vec{y}$ a $H$ es

\[ \begin{aligned} d(\vec{y}, H) &= \|\vec{y} - \text{proy}_H\vec{y}\| \\[0.5em] &= \|\text{proy}_{H^\perp}\vec{y}\|. \end{aligned} \]

Análogamente, la distancia de $\vec{y}$ a $H^\perp$ es $d(\vec{y}, H^\perp) = \|\text{proy}_H\vec{y}\|$.

MÓDULO 04 Proceso de Gram-Schmidt

En la práctica, los subespacios suelen venir definidos por bases arbitrarias que no son ortogonales ni ortonormales. El proceso de Gram-Schmidt transforma cualquier base linealmente independiente en una base ortonormal, sin alterar el subespacio generado.

4.1 Algoritmo

📐 Teorema 6.8 (Gram-Schmidt)

Dada una base $\{\vec{x}_1,\dots,\vec{x}_p\}$ de $W$, se definen:

\[ \begin{aligned} \vec{v}_1 &= \vec{x}_1 \\[0.5em] \vec{v}_2 &= \vec{x}_2 - \frac{\vec{x}_2\cdot\vec{v}_1}{\vec{v}_1\cdot\vec{v}_1}\vec{v}_1 \\[0.5em] \vec{v}_3 &= \vec{x}_3 - \frac{\vec{x}_3\cdot\vec{v}_1}{\vec{v}_1\cdot\vec{v}_1}\vec{v}_1 \\[0.3em] &\quad - \frac{\vec{x}_3\cdot\vec{v}_2}{\vec{v}_2\cdot\vec{v}_2}\vec{v}_2 \\[0.5em] &\vdots \\[0.5em] \vec{v}_k &= \vec{x}_k - \sum_{j=1}^{k-1} \frac{\vec{x}_k\cdot\vec{v}_j}{\vec{v}_j\cdot\vec{v}_j}\,\vec{v}_j. \end{aligned} \]

Entonces $\{\vec{v}_1,\dots,\vec{v}_p\}$ es una base ortogonal de $W$. Además, $\langle\vec{v}_1,\dots,\vec{v}_k\rangle = \langle\vec{x}_1,\dots,\vec{x}_k\rangle$ para todo $k$.

Finalmente, normalizando $\vec{u}_k = \vec{v}_k/\|\vec{v}_k\|$ se obtiene una base ortonormal.

Proceso de Gram-Schmidt paso a paso

4.2 Ejemplo Completo

🧩 Ejemplo 4.1: base ortonormal para el plano $x+y+z=0$

Sea $H$ el plano $x+y+z=0$ en $\mathbb{R}^3$. Encontrar una base ortonormal para $H$.

🔍 Ver solución paso a paso

1) Base inicial. Despejando $z = -x-y$, un vector genérico es $(x,y,-x-y)$, de donde

\[ \begin{aligned} \mathbf{w}_1 &= (1,0,-1), \\[0.5em] \mathbf{w}_2 &= (0,1,-1). \end{aligned} \]

2) ¿Son ortogonales?

\[ \begin{aligned} \mathbf{w}_1\cdot\mathbf{w}_2 &= 0 + 0 + 1 \\[0.5em] &= 1 \neq 0 \;\Rightarrow\; \text{no ortogonal}. \end{aligned} \]

3) Primero ortogonalizamos.

\[ \mathbf{v}_1 = \mathbf{w}_1 = (1,0,-1). \]

Proyección de $\mathbf{w}_2$ sobre $\mathbf{v}_1$:

\[ \begin{aligned} \mathbf{w}_2\cdot\mathbf{v}_1 &= 1, \\[0.5em] \|\mathbf{v}_1\|^2 &= 2, \\[0.5em] \text{proy} &= \tfrac{1}{2}(1,0,-1) \\[0.5em] &= \left(\tfrac{1}{2},0,-\tfrac{1}{2}\right). \end{aligned} \] \[ \begin{aligned} \mathbf{v}_2 &= \mathbf{w}_2 - \text{proy} \\[0.5em] &= \left(0,1,-1\right) - \left(\tfrac{1}{2},0,-\tfrac{1}{2}\right) \\[0.5em] &= \left(-\tfrac{1}{2},1,-\tfrac{1}{2}\right). \end{aligned} \]

Escalamos (para evitar fracciones):

\[ \mathbf{v}_2 \to (-1,2,-1). \]

Verificación: $\mathbf{v}_1\cdot\mathbf{v}_2 = -1 + 0 + 1 = 0$ ✓

4) Normalizamos.

\[ \begin{aligned} \|\mathbf{v}_1\| &= \sqrt{2}, \\[0.5em] \|\mathbf{v}_2\| &= \sqrt{6}. \end{aligned} \] \[ \begin{aligned} \mathbf{u}_1 &= \left(\tfrac{1}{\sqrt{2}},0,-\tfrac{1}{\sqrt{2}}\right), \\[0.5em] \mathbf{u}_2 &= \left(-\tfrac{1}{\sqrt{6}},\tfrac{2}{\sqrt{6}},-\tfrac{1}{\sqrt{6}}\right). \end{aligned} \]

5) Comprobación.

\[ \begin{aligned} \mathbf{u}_1\cdot\mathbf{u}_2 &= 0, \\[0.5em] \|\mathbf{u}_1\| &= 1, \\[0.5em] \|\mathbf{u}_2\| &= 1. \end{aligned} \]

La base ortonormal de $H$ es $\{\mathbf{u}_1,\mathbf{u}_2\}$.

🧩 Ejemplo 4.2: complemento $H^\perp$, proyección y matriz $Q$

Con el mismo $H$ del ejemplo anterior y $\mathbf{v}=(1,2,3)$, calcular $H^\perp$, la proyección $\text{proy}_H\mathbf{v}$ y la matriz ortogonal $Q$.

🔍 Ver solución

Complemento ortogonal. La ecuación implícita $x+y+z=0$ tiene vector normal $\mathbf{n}=(1,1,1)$. Normalizado:

\[ \begin{aligned} \mathbf{u}_3 &= \left(\tfrac{1}{\sqrt{3}},\tfrac{1}{\sqrt{3}},\tfrac{1}{\sqrt{3}}\right), \\[0.5em] H^\perp &= \operatorname{gen}\{\mathbf{u}_3\}. \end{aligned} \]

Matriz ortogonal. Tomando $\mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3$ como columnas:

\[ Q = \begin{pmatrix} \tfrac{1}{\sqrt{2}} & -\tfrac{1}{\sqrt{6}} & \tfrac{1}{\sqrt{3}} \\ 0 & \tfrac{2}{\sqrt{6}} & \tfrac{1}{\sqrt{3}} \\ -\tfrac{1}{\sqrt{2}} & -\tfrac{1}{\sqrt{6}} & \tfrac{1}{\sqrt{3}} \end{pmatrix}, \quad Q^{-1} = Q^t. \]

Proyección.

\[ \begin{aligned} \mathbf{v}\cdot\mathbf{u}_1 &= \tfrac{1}{\sqrt{2}} + 0 - \tfrac{3}{\sqrt{2}} \\[0.5em] &= -\tfrac{2}{\sqrt{2}}, \end{aligned} \] \[ \begin{aligned} \mathbf{v}\cdot\mathbf{u}_2 &= -\tfrac{1}{\sqrt{6}} + \tfrac{4}{\sqrt{6}} - \tfrac{3}{\sqrt{6}} \\[0.5em] &= 0. \end{aligned} \] \[ \begin{aligned} \text{proy}_H\mathbf{v} &= -\tfrac{2}{\sqrt{2}}\left(\tfrac{1}{\sqrt{2}},0,-\tfrac{1}{\sqrt{2}}\right) \\[0.5em] &= (-1,0,1). \end{aligned} \]

Comprobación. $(-1)+0+1=0$ ✓ (pertenece a $H$); además $\mathbf{v}-\text{proy}_H\mathbf{v} = (2,2,2) \propto (1,1,1) \in H^\perp$ ✓.

MÓDULO 05 Espacios Fundamentales de una Matriz

5.1 Los Cuatro Espacios

📌 Definición

Sea $A$ una matriz $m\times n$. Se definen:

Espacio Subespacio de Definición Dimensión
Nulo $N_A$ $\mathbb{R}^n$ $\{\vec{x} \in \mathbb{R}^n : A\vec{x} = \vec{0}\}$ $nul(A)$
Imagen $\text{Im}(A)$ $\mathbb{R}^m$ $\{\vec{y} : A\vec{x} = \vec{y}\ \text{para algún}\ \vec{x}\}$ $ran(A)$
Renglones $R_A$ $\mathbb{R}^n$ $\operatorname{gen}\{\vec{r}_1,\dots,\vec{r}_m\}$ $ran(A)$
Columnas $C_A$ $\mathbb{R}^m$ $\operatorname{gen}\{\vec{c}_1,\dots,\vec{c}_n\}$ $ran(A)$

El espacio de columnas coincide con la imagen $(C_A = \text{Im}(A))$. Además, se cumple la relación fundamental entre ecuaciones implícitas y complemento ortogonal:

\[ \operatorname{Col}(A)^\perp = \operatorname{Nul}(A^t). \]

5.2 Teorema de Estructura

📐 Propiedades estructurales
PropiedadRelación / condición
Rango-Nulidad $ran(A) + nul(A) = n$
Dimensiones $\dim R_A = \dim C_A$
$= \dim\text{Im}(A) = ran(A)$
Invarianza Si $A\sim B$, comparten $R_A$, rango y nulidad.
$\operatorname{rg}(A)$ = número de pivotes.
Invertibilidad $(n\times n)$ $A$ invertible
$\Leftrightarrow ran(A) = n$
$\Leftrightarrow nul(A) = 0$
Consistencia $A\vec{x}=\vec{b}$ tiene solución
$\Leftrightarrow \vec{b}\in C_A$
$\Leftrightarrow ran(A) = ran(A\mid\vec{b})$

5.3 Ejemplo

🧩 Ejemplo 5.1: espacios fundamentales de una matriz $3\times4$

Sistema homogéneo:

\[ \begin{aligned} x_1 + 2x_2 - x_3 + x_4 &= 0 \\[0.5em] 2x_1 + 4x_2 - x_3 + 3x_4 &= 0 \\[0.5em] -x_1 - 2x_2 + 2x_3 &= 0 \end{aligned} \]
🔍 Ver solución

Matriz aumentada y Gauss-Jordan:

\[ \begin{aligned} A &= \begin{pmatrix}1&2&-1&1\\2&4&-1&3\\-1&-2&2&0\end{pmatrix} \\[0.5em] &\sim R = \begin{pmatrix}1&2&0&2\\0&0&1&1\\0&0&0&0\end{pmatrix}. \end{aligned} \]

Espacio fila. Filas no nulas de $R$:

\[ \operatorname{Base}(R_A) = \{(1,2,0,2),\, (0,0,1,1)\}, \quad \dim = 2. \]

Interpretación: el sistema original tiene solo dos restricciones independientes.

Espacio columna. Columnas pivotales (1 y 3) de $A$:

\[ \operatorname{Base}(C_A) = \left\{\begin{pmatrix}1\\2\\-1\end{pmatrix}, \begin{pmatrix}-1\\-1\\2\end{pmatrix}\right\}, \quad \dim = 2. \]

Espacio nulo. Con $x_2=s$, $x_4=t$ libres:

\[ \begin{aligned} x_1 &= -2s-2t, \\[0.5em] x_3 &= -t, \end{aligned} \] \[ \operatorname{Base}(N_A) = \left\{\begin{pmatrix}-2\\1\\0\\0\end{pmatrix}, \begin{pmatrix}-2\\0\\-1\\1\end{pmatrix}\right\}, \quad \dim = 2. \]

Verificación rango-nulidad: $2 + 2 = 4 = n$ ✓

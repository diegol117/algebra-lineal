# Álgebra Lineal y Sucesiones — Recursos Académicos 📐

¡Bienvenido al repositorio oficial de recursos académicos para la asignatura **Álgebra Lineal y Sucesiones**! Este espacio ha sido diseñado para centralizar material de apoyo, el temario oficial y un banco de ejercicios prácticos para estudiantes y entusiastas de las matemáticas.

🌐 **Accede al sitio web aquí:** [https://diegol117.github.io/algebra-lineal/](https://diegol117.github.io/algebra-lineal/)

---

## 🎯 Objetivo del Proyecto
Proporcionar una plataforma accesible y organizada con recursos de alta calidad sobre los fundamentos del álgebra lineal y el análisis de sucesiones, facilitando el aprendizaje autodidacta, el repaso de conceptos clave y la preparación para evaluaciones.

## 🗂️ Contenido del Repositorio
En este sitio encontrarás material detallado y herramientas de apoyo sobre:

* **Matrices, Determinantes y Sistemas:** Operaciones, matrices inversas, eliminación de Gauss-Jordan y análisis de consistencia.
* **Espacios Vectoriales:** Subespacios, dependencia lineal, bases, dimensión, cambio de base y proyecciones ortogonales.
* **Transformaciones Lineales:** Núcleo, imagen, representación matricial, rango y nulidad.
* **Autovalores y Autovectores:** Polinomio característico, matrices semejantes y diagonalización.
* **Sucesiones y Series:** Límites, criterios de convergencia, series geométricas, telescópicas y alternantes.
* **Autoevaluaciones:** Banco de más de 50 ejercicios de práctica con soluciones paso a paso.
* **Herramientas Interactivas:** Enlaces directos a GeoGebra y MatrixCalc para verificación de cálculos y visualización geométrica.

## 🚀 Tecnologías Utilizadas
Este recurso ha sido construido utilizando:
* **HTML5 y CSS3** para la estructura y el diseño responsivo y moderno.
* **JavaScript** para los componentes interactivos (como el despliegue de soluciones).
* **KaTeX** para el renderizado de alta calidad de fórmulas y matrices matemáticas.
* **GitHub Pages** para el despliegue y hosting gratuito.
